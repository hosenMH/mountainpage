# واجب إنشاء صفحة HTML

قمت بإنشاء صفحة `index.html` تعرض صورة جبال مع أقسام بسيطة وتنقل بين الأجزاء، وإضافة تعليقات على كل جزء في الكود.

## الملفات المرفوعة
- `index.html`: كود الصفحة الرئيسي.
- `IMG_7458.jpeg`: صورة الجبال المستخدمة في الصفحة.
- `README.md`: ملف شرح بسيط للمشروع.

## شرح مختصر للكود
- **head**: يحتوي على الترميز ومقاسات الشاشة وعنوان الصفحة.
- **header**: فيه عنوان الصفحة وروابط التنقل.
- **main**: يقسم الصفحة إلى أجزاء (`section`) للصورة، وصف المشهد، ونموذج التواصل.
- **footer**: الجزء السفلي لحقوق النشر.
